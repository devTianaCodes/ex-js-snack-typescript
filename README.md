# JS Snack TypeScript

Progetto Vite configurato con TypeScript per scrivere esercizi JavaScript in modo tipizzato.

## Requisiti

- Node.js 18 o superiore
- npm

## Script disponibili

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Struttura

```text
src/
  main.ts
  style.css
```

## Pubblicazione su GitHub

Il repository contiene gia' `.gitignore`, licenza MIT, README e configurazione TypeScript/Vite. Dopo aver creato un repository vuoto su GitHub:

```bash
git remote add origin https://github.com/<utente>/<repo>.git
git branch -M main
git push -u origin main
```
